Unify configuration file path to `~/.config/cdx/config.toml` across platforms and remove `directories` dependency.

## What's Changed

### 🐛 Bug Fixes
- **Unified Configuration Path**: Changed `get_config_path()` to consistently resolve `~/.config/cdx/config.toml` using `std::env::home_dir()` instead of OS-specific application support directories (such as `~/Library/Application Support/cdx/config.toml` on macOS).

### 🔧 Maintenance & Dependencies
- **Remove `directories` Dependency**: Replaced `directories` crate usage with Rust 2024 standard library's `std::env::home_dir()`.

### 📚 Documentation
- Added logo image and refined header layout in `README.md`.
