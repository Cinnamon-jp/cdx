Initial release of cdx — an accelerated, interactive directory navigation tool.

## What's Changed

### 🚀 Features
- **Interactive TUI Mode**: Navigate directories with an intuitive, terminal-based interface powered by `crossterm`.
- **Direct Mode**: Support passing target paths as arguments (`cdx <path>`) for non-interactive resolution.
- **Incremental Search**: Quickly filter directory entries with prefix matching as you type.
- **Keyboard Navigation**:
  - `Up` / `Down`: Move selection
  - `Tab`: Enter selected directory
  - `Enter`: Confirm current directory (`.`) and exit
  - `Backspace`: Delete search character or go to parent directory when input is empty
  - `Esc` / `Ctrl-C`: Cancel and exit
- **Shell Integration**: Provided shell wrapper configurations for `bash`, `zsh`, and `fish`.
- **Open Source**: Released under the MIT License.
