Prevent alias recursion by using `builtin cd` in shell wrappers.

## What's Changed

### 🐛 Bug Fixes
- **Shell Wrapper Recursion**: Use `builtin cd` instead of `cd` in shell wrapper scripts (`bash`, `zsh`, `fish`) to prevent recursive execution loops when `cd` is aliased.
