Redirect TUI rendering output to stderr for clean stdout capture.

## What's Changed

### ⚡ Improvements
- **Output Redirection**: Changed TUI rendering output from `stdout` to `stderr`. This ensures shell wrappers and subshells (`cd "$(cdx)"`) only capture the final selected path on `stdout`, preventing terminal control sequences from polluting output.
