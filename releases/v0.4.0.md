Partial path navigation fallback, `--version` CLI flag, and release automation.

## What's Changed

### 🚀 Features
- **Partial Path Navigation Fallback**: When navigating to a non-existent or partially invalid path (`cdx <path>`), cdx can now automatically traverse up to the deepest existing ancestor directory and launch interactive TUI mode from there (enabled via `partial_navigation_fallback = true` under `[system]`).
- **`--version` CLI Option**: Added `cdx --version` to display the current version.
- **Configuration Key Renaming**: Renamed `use_case_insensitive_search` to `case_insensitive_search` in `[system]` config and updated `config.schema.json`.

### ⚡ Refactoring & Testing
- **CLI Argument & Path Resolution Refactoring**: Decomposed CLI argument handling using slice pattern matching and encapsulated path resolution with a dedicated `ResolveError` enum.
- **Path Resolution Unit Tests**: Added unit tests for ancestor path traversal (`find_deepest_dir`) and resolution fallback behaviors.
- **Partial Configuration Parsing Tests**: Added unit tests to ensure missing or partial `[ui]` and `[system]` TOML tables fall back safely to defaults.

### 🔧 Maintenance & CI
- **Automated GitHub Releases**: Added `release.yaml` workflow to create GitHub Releases with corresponding release notes from `releases/v*.*.*.md` upon tagging.
- **Automated Crates.io Publishing**: Added `publish.yaml` workflow to automate publishing to crates.io upon release.
- **Historical Release Notes**: Documented release notes for all previous versions (`v0.1.0` through `v0.3.2`).
- **Dependency Updates**: Updated `Cargo.lock` dependencies to their latest versions.

### 📚 Documentation
- Updated `README.md` and `config.schema.json` with the new system configuration options (`case_insensitive_search`, `partial_navigation_fallback`).
- Added home directory transition to Planned Features in `README.md`.
