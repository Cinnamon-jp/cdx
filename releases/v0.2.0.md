TOML configuration support, hex/named color customization, and direct Enter selection.

## What's Changed

### 🚀 Features
- **TOML Configuration**: Support custom user configuration via `~/.config/cdx/config.toml`.
  - Color themes: Customize `selected_background_color`, `selected_foreground_color`, and `path_foreground_color` with named colors or hex RGB (`#RGB`, `#RRGGBB`).
  - Search behavior: Toggle case-insensitive search via `use_case_insensitive_search`.
- **JSON Schema Support**: Included `config.schema.json` for validation and auto-completion in TOML-aware editors (e.g. Even Better TOML).

### ⚡ Improvements
- **Direct Selection with Enter**: Pressing `Enter` on any highlighted directory (including `.` and `..`) now immediately confirms and switches to that directory. `Tab` continues to navigate deeper while remaining in interactive mode.
- **TUI Rendering**: Enhanced viewport calculations, scrolling behavior, and terminal resize handling.

### 🔧 Maintenance & Refactoring
- **Codebase Modularization**: Decomposed codebase into clean domain modules (`app.rs`, `config.rs`, `fs.rs`, `ui.rs`, `tui.rs`).
- **Test Suite**: Added comprehensive unit tests covering configuration parsing, filtering, navigation, and filesystem queries.
- **Dependencies**: Added `directories`, `serde`, and `toml` crates.
