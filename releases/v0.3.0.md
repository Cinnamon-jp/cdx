Shell integration with `cdx init`, crates.io readiness as `cdx-rs`, and CI workflows.

## What's Changed

### 🚀 Features
- **Shell Integration Command (`cdx init`)**: Added `init` subcommand for easy shell setup across multiple shells:
  - Bash: `eval "$(cdx init bash)"`
  - Zsh: `eval "$(cdx init zsh)"`
  - Fish: `cdx init fish | source`

### 🔧 Maintenance & CI
- **Crates.io Publication Readiness**: Configured package metadata for publishing to crates.io as `cdx-rs`.
- **GitHub Actions CI**: Added automated workflows for testing, linting (`clippy`), and formatting checks (`rustfmt`).

### 📚 Documentation
- Updated `README.md` to document the new `cdx init` setup and manual configuration fallback.
